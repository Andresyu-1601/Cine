## Descripción
Programa en Python que gestiona la reserva de asientos en una sala de cine pequeña (3 filas por 4 columnas). Permite al usuario seleccionar una fila y una columna, actualiza la matriz y muestra el estado final de la sala.

## Estructura del Estado de la Sala
- `0`: Asiento disponible (Libre)
- `1`: Asiento ocupado (Reservado)

## Cómo ejecutar el programa
1. Tener instalado Python 3.
2. Ejecutar desde la terminal o consola:
   python cine.py
